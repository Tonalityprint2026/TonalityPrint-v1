  STEP 2: LOAD ANNOTATION DATA

Python Example:
---------------
import pandas as pd
import json

# Load combined CSV (all 144 annotations)
df = pd.read_csv('annotations/ALL_TONALITY_DATA_COMBINED.csv')

# Display basic info
print(f"Total samples: {len(df)}")
print(f"Columns: {df.columns.tolist()}")

# Parse segment-level JSON data
df['Segments_Parsed'] = df['Segments'].apply(json.loads)

# Preview first few rows
print(df.head())

R Example:
----------
library(readr)

data <- read_csv('annotations/ALL_TONALITY_DATA_COMBINED.csv')

# Parse segment-level JSON data

═══════════════════════════════════════════════════════════════════════════
  STEP 3: ACCESS AUDIO FILES
═══════════════════════════════════════════════════════════════════════════

Python Example (using librosa):
--------------------------------
import librosa
import numpy as np

# Load a single audio file
audio_path = 'audio/TPV1_B1_UTT1_S_Att_SP-Ronda.wav'
audio, sr = librosa.load(audio_path, sr=48000, mono=True)

print(f"Sample rate: {sr} Hz")
print(f"Duration: {len(audio)/sr:.2f} seconds")
print(f"Audio shape: {audio.shape}")

# Extract MFCC features
mfcc = librosa.feature.mfcc(y=audio, sr=sr, n_mfcc=13)
print(f"MFCC shape: {mfcc.shape}")

# Extract pitch (F0)
f0 = librosa.yin(audio, fmin=75, fmax=300, sr=sr)
print(f"Pitch range: {np.nanmin(f0):.1f} - {np.nanmax(f0):.1f} Hz")

Python Example (using scipy):
------------------------------
from scipy.io import wavfile

# Load audio file (preserves original 48kHz, 16-bit)

print(f"Sample rate: {sr} Hz")
print(f"Data type: {audio.dtype}")
print(f"Duration: {len(audio)/sr:.2f} seconds")

Audio Specifications:
---------------------
- Format: WAV (uncompressed PCM)
- Sample Rate: 48,000 Hz (48kHz)
- Bit Depth: 16-bit
- Channels: Mono (1 channel)
- Duration: 3-6 seconds per file
- Processing: None (raw, unprocessed audio)

File Naming Convention:
-----------------------
TPV1_[Batch]_[Utterance]_[Type]_[Intent]_[Modifier]_[Ambivalex]_SP-Ronda.wav

Examples:
- TPV1_B1_UTT1_S_Att_SP-Ronda.wav (Single - Attention only)
- TPV1_B1_UTT1_S_Reci_affi_SP-Ronda.wav (Compound - Reciprocity + Affirming)
- TPV1_B1_UTT1_S_Reci_affi_ambivalex_SP-Ronda.wav (Complex - with Ambivalence)

Task 1: Filter by Primary Intention
------------------------------------
# Get all "Trust" samples
trust_samples = df[df['Primary_Intention'] == 'Trust']
print(f"Trust samples: {len(trust_samples)}")

# Get all samples with ambivalence
ambivalent_samples = df[df['Ambivalex'] == 'ambivalex']
print(f"Ambivalent samples: {len(ambivalent_samples)}")

# Get Trust samples with "calm" sub-modifier
trust_calm = df[
    (df['Primary_Intention'] == 'Trust') & 
    (df['Sub_Modifier'] == 'calm')
]

Task 2: Analyze Tonality Indices
---------------------------------
# Compare tonality scores across intentions
import matplotlib.pyplot as plt

# Average Trust scores by Primary Intention
trust_by_intent = df.groupby('Primary_Intention')['Trust_Index'].mean()
print(trust_by_intent)

# Visualize distribution
df['Cognitive_Energy_Index'].hist(bins=20)
plt.xlabel('Cognitive Energy Score')
plt.ylabel('Frequency')
plt.title('Cognitive Energy Distribution (Note: Systematic Elevation)')
plt.show()

# Note: Cognitive Energy shows known systematic bias (~86-100 range)
# See README.md and METHODOLOGY.md for details

Task 3: Contrastive Analysis (Fixed-Phrase Octet)
--------------------------------------------------
# Compare same utterance across different intentions
utt1_samples = df[df['Utterance_Number'] == 'UTT1']

# Extract indices for comparison
intentions = utt1_samples['Primary_Intention'].tolist()
trust_scores = utt1_samples['Trust_Index'].tolist()
attention_scores = utt1_samples['Attention_Index'].tolist()

═══════════════════════════════════════════════════════════════════════════
  IMPORTANT LIMITATIONS
═══════════════════════════════════════════════════════════════════════════

⚠ SINGLE SPEAKER: All 144 files from same speaker (Ronda Polhill)
   → Findings may not generalize across genders, ages, accents, cultures
   → State explicitly: "single-speaker dataset" in publications

⚠ CONTROLLED ENVIRONMENT: Professional studio recordings, scripted content
   → May not reflect naturalistic speech conditions
   → Do not generalize to noisy, real-world scenarios without validation

⚠ COGNITIVE ENERGY BIAS: Systematic elevation across corpus
   → Most samples score 86-100 on Cognitive Energy scale
   → Account for bias in analyses, see Notes field in data

⚠ PERCEPTUAL SCORES: Tonality indices are annotator perceptions, not validated scales
   → Treat as exploratory, not ground truth
   → Single annotator (no inter-rater reliability)

⚠ OBSERVATIONAL CONTEXT: 8,873+ interactions referenced (correlation, not causation)
   → Do not claim causal relationships without additional evidence
